My Library

Organize your books, categories, and authors in Odoo.

Overview

A simple library module for managing a collection of books, organized by category and linked to Odoo contacts.

Key Features

  • Maintain book titles, authors, and ISBNs.
  • Organize books by category.
  • Link books to contacts (authors, publishers).
  • Control access with dedicated Librarian and User groups.

Getting Started

  1. Install the module and open the Library menu.
  2. Create a few book categories.
  3. Add books and assign them a category.
  4. Assign users to a library group under Settings → Users.
